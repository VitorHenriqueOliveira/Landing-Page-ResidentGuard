## 📝 O que é ResidentGuard?

ResidentGuard é uma aplicação que tem como objetivo facilitar o controle de entrada e saída de um condomínio. Com o sistema, será possível organizar a entrega de encomendas, agendar o uso de áreas comuns e salvar informações de moradores e visitantes no banco de dados, tudo de forma digital, rápida e organizada.

Além de tudo, é um Trabalho de Conclusão de Curso apresentado como exigência Parcial para obtenção da Habilitação Profissional Técnica de Nível Médio de Técnico em Desenvolvimento de Sistemas.

---

## 🖥️ Como acessar?

Para ter acesso a todas as funcionalidades da aplicação, é necessário ter permissão administrativa, obtida por meio de nome de usuário e senha fornecidos diretamente pelos desenvolvedores. Ainda assim, é possível experimentar uma pequena amostra do projeto.
